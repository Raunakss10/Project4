# Do Healthy Recipes Get Lower Ratings?

### A Data Science Investigation

This project analyzes a dataset of recipes to explore whether recipes labeled as "healthy" receive lower ratings from users.

The analysis includes:
- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical testing
- Visualization of rating patterns
